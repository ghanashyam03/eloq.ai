# Adaptive Learning and Practice Engine Architecture

## Overview

The Adaptive Learning and Practice Engine determines what exercise a learner should practice next to maximize expected learning value ($ELV$). Rather than generating generic or random exercises, the subsystem prioritizes evidence from active recurring weaknesses, due Spaced Repetition System (SRS) reviews, goal alignment, and historical performance.

---

## 1. Expected Learning Value ($ELV$) Prioritization Formula

Candidate learning targets are scored using a deterministic formula:

$$ELV = (P_{\text{weakness}} \times 0.35) + (W_{\text{goal}} \times 0.25) + (U_{\text{srs}} \times 0.20) + (\text{FailureRate} \times 0.15) + (\text{RecencyDecay} \times 0.05)$$

### Factor Breakdown

- **$P_{\text{weakness}}$ (Weakness Priority Score, 0–10)**: Priority calculated by the `WeaknessCalculator` based on frequency, persistence, and recency.
- **$W_{\text{goal}}$ (User Goal Weight, 0–10)**: Alignment score between candidate category and explicit user learning goals (e.g. academic, conversational, business).
- **$U_{\text{srs}}$ (SRS Review Urgency, 0–10)**: Calculated by `SRSScheduler` based on days overdue past scheduled `nextReviewAt`.
- **$\text{FailureRate}$ (Historical Failure Rate, 0–10)**: Ratio of incorrect attempts on this specific target skill.
- **$\text{RecencyDecay}$ (Recency Factor, 0–10)**: Decay function ($10 - 0.3 \times \text{daysSinceLastSeen}$) prioritizing active learning context.

---

## 2. 5-Stage Pedagogical Progression Model

A learner's weakness or skill progresses through 5 systematic stages:

```
[Stage 1: Recognition] ──> [Stage 2: Controlled Production] ──> [Stage 3: Guided Production] ──> [Stage 4: Spontaneous Production] ──> [Stage 5: Real Conversation]
```

1. **`recognition`**: Multiple choice or option identification.
2. **`controlled_production`**: Sentence gap fill, grammar transformation, or error correction.
3. **`guided_production`**: Sentence creation with specified target collocations.
4. **`spontaneous_production`**: Speaking prompt response or open concept explanation.
5. **`real_conversation`**: Integration into unscripted voice conversation scenarios.

---

## 3. Smooth Adaptive Difficulty Scaling (CEFR)

Difficulty adjusts smoothly between `A1` and `C2` based on consecutive attempt performance:

- **2 Consecutive Successes**: Advance progression stage (e.g. `controlled_production` $\rightarrow$ `guided_production`) and increase CEFR difficulty by +1 level (e.g. `B1` $\rightarrow$ `B2`).
- **2 Consecutive Failures**: Regress progression stage (e.g. `guided_production` $\rightarrow$ `controlled_production`) and reduce CEFR difficulty by -1 level (e.g. `B1` $\rightarrow$ `A2`) to provide scaffolding hints.
- **Stable Performance**: Maintain current stage and difficulty.

---

## 4. Transparent Explainability (`selectionReason`)

Every exercise generated by the engine includes a human-readable, evidence-backed selection reason:

> **Example**: *"Selected because preposition 'interested in' is currently a high-priority recurring weakness (Priority Score: 8.5, Sessions: 3) and has not been mastered in spontaneous usage."*
> **Example**: *"Selected because vocabulary term 'mitigate' is past its review schedule (Urgency: 8.5) and requires active retrieval maintenance."*
